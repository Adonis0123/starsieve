已被 2026-11-20-overview-local.md 取代。目标设计快照，写于 2026-11-20，不随代码更新；与代码冲突时以代码为准，并报告不一致。

## Components

| Name | Type | Responsibility | Code path |
|---|---|---|---|
| starsieve CLI | backend | Deterministic commands: `check`, `collect`, `pending`, `apply`, `publish --dry-run`, `lists sync`; no built-in LLM | `Adonis0123/starsieve` `src/cli` (planned) |
| starsieve Panel | frontend | One frontend, two builds: Portal Panel via `createPanelHandler` (all items) and public static site (public projection only) | `Adonis0123/starsieve` `src/panel` (planned) |
| starsieve Skill | agent skill | Routes natural language to CLI commands; installed into the Grok Bot cloud skill library | `Adonis0123/starsieve` `skill/` (planned) |
| Grok Bot `starsieve` | cloud agent | Daily routine: runs CLI, reads X likes/bookmarks through its X connection, writes classification JSON | grok.com/bot (cloud) |
| `<owner>/stars-private` | private repo | Every Item (GitHub + X), raw payloads, classifications, Category table, backfill cursor | GitHub (planned) |
| `<owner>/stars` | public repo | Public projection JSON, generated README catalog, Pages site, status.json heartbeat | GitHub (planned) |
| Required check workflow | CI | Second line of defense (the PR is already public): validates schema, only data files changed, no private Item; gates auto-merge | `stars/.github/workflows` (planned) |
| Lists sync workflow | CI | On push to main, reads existing Lists, merges Category membership, never deletes | `stars/.github/workflows` (planned) |
| Heartbeat workflow | CI | Opens an issue when the heartbeat in stars-private (updated every run, even when nothing is new) is older than 48h | `stars-private/.github/workflows` (planned) |
| Local Portal | local gateway | Serves the Panel at a local address from a local clone of stars-private | an entry in the Portal's `portal.json` |

## Relationships

| From | To | Action | Protocol / data |
|---|---|---|---|
| Grok Bot | X | Reads new likes/bookmarks, then backfills newest-to-oldest one segment per run | Grok X connection |
| starsieve CLI | GitHub API | Lists starred repos, stops at last known id | REST `GET /user/starred` |
| Grok Bot | starsieve CLI | Runs `check`; exits when nothing is new | shell |
| starsieve CLI | Grok Bot | `pending --limit 25` emits classification input | JSON |
| Grok Bot | starsieve CLI | `apply` submits batch (schemaVersion, batchId, inputHash, category, tags, visibility, summary, needsReview) | JSON file |
| starsieve CLI | stars-private | Commits every Item and classification | git push |
| starsieve CLI | stars | `publish` filters before push (visibility=public only, drops stars of private repos), then opens daily PR | git + GitHub PR, repo-scoped credential |
| stars PR | Required check | Validates before auto-merge | GitHub Actions status check |
| Required check | stars main | Auto-merges on pass | `gh pr merge --auto` |
| stars main | Lists sync workflow | Triggers on push | `push` event, environment secret with classic `user` PAT |
| Lists sync workflow | GitHub Lists | Reads then merges Category membership | GraphQL `updateUserListsForItem` |
| stars main | Pages | Builds public static site and README | GitHub Pages |
| Local Portal | stars-private clone | Reads all Items for local browsing | file system |
